# Rowan Vale Therapy

Private psychotherapy practice site for **Chelsea, New York City**. Next.js, TypeScript, and Tailwind CSS.

## Pages

- Home
- About
- Services & fees
- Approach
- First session
- FAQ
- Contact
- Privacy
- Practice policies

## Develop

```bash
npm install
npm run dev
```

```bash
npm run lint
npm run type-check
npm run build
```

To email contact-form submissions, copy `.env.example` to `.env.local` and add a Resend API key.

Practice copy lives in `lib/site.ts`.

# Haven Path Therapy

A premium, editorial website for a private therapy practice. Next.js, TypeScript, and Tailwind CSS.

Practice name, clinician bio, fees, and location are **sample content**. Edit `lib/site.ts` before you publish.

## Pages

- Home — cinematic hero, specialties, studio image, approach, composite reflections, fees
- About, Services, Approach, FAQ, Contact, Privacy

Includes a 988 crisis banner, skip-to-content, JSON-LD, security headers, and a validated contact form.

## Customize

1. Open `lib/site.ts`.
2. Replace the clinician name, license, city, fees, and email.
3. Swap the images in `public/images/` for real studio or portrait photography.
4. Update `site.url` with the live domain.
5. Have an attorney review the privacy page.
